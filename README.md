# Лабораторная работа 9. Вложенные списки и таблицы

Выполнил: Вариант 1 (Отрицательные элементы заменить нулями)

## Описание программ

- `table.py` - модуль, содержащий функции для вычисления сумм строк и столбцов матрицы, генерации диагонального узора и преобразования матрицы по варианту без изменения оригинала.
- `main.py` - интерактивный скрипт для ввода матрицы с проверкой размерности, вывода результатов обработки и генерации узора.
- `test_table.py` - набор автоматических проверок (`assert`) корректности матричных функций.

## Команды запуска

- Запуск основной программы:

  python main.py
